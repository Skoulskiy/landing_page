# 🎨 NAMU — National Art Museum of Ukraine

> **Responsive, pixel-perfect landing page** for the National Art Museum of Ukraine, built with semantic HTML5, modern SCSS (BEM architecture), and flexible custom CSS Grid/Flexbox layouts.

## 📌 Project Overview
The goal of this project is to present the rich heritage of the National Art Museum of Ukraine through a sleek, modern, and accessible web interface. It showcases current exhibitions, historical context, ticket purchasing details, visitor schedules, and location maps.

Key focus areas during development were **pixel-perfect fidelity to Figma layouts**, **pure CSS/SCSS architecture without utility frameworks**, and **high performance across desktop, tablet, and mobile devices**.

---

## 💡 Engineering & Architecture Highlights

* **Pure BEM Methodology**: Zero style leaks and high component reusability using strict Block-Element-Modifier structure.
* **Custom Responsive Grid**: Dynamic layout adapting from a 6-column grid on mobile to a 12-column system on desktop, completely tailored to match exact Figma design tokens.
* **Fluid Layouts**: Built using `min()`, `max()`, and `clamp()` CSS functions to ensure smooth scaling between custom breakpoints (`320px`, `640px`, `768px`, `1280px`).
* **Optimized Build**: Powered by Vite for lightning-fast HMR and minified production builds.

## 💻 Local Development Setup

Follow these steps to run the project locally on your machine:

### Prerequisites
* **Node.js**: `v18.x` or higher recommended
* **npm**: `v9.x` or higher

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Skoulskiy/landing_page
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
  ```bash
   npm start
   ```
4. **Build for production:**
  ```bash
  npm run build
  ```
